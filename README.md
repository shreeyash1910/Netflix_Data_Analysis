# 🎬 Netflix Data Analysis using Python

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the Netflix Movies and TV Shows dataset using Python. The objective is to clean the dataset, handle missing values, perform statistical analysis, and create insightful visualizations using Pandas, NumPy, Matplotlib, and Seaborn.

The project demonstrates the complete data analysis workflow, from loading raw data to generating meaningful business insights through graphical representations.

---

## 🎯 Objectives

- Load and inspect the dataset
- Clean and preprocess the data
- Handle missing values
- Remove duplicate records
- Perform Exploratory Data Analysis (EDA)
- Create informative visualizations
- Generate meaningful business insights
